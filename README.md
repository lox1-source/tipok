# Типочек: Ключ

Сюжетное приключение с исследованием, диалогами и мини-играми. Версия проекта — 1.0.0.

## Запуск исходников

Откройте файл `project.godot` в Godot 4.7.2, дождитесь импорта ресурсов и нажмите F5. Начальная сцена — `Disclaimer.tscn`.

В `assets/` находятся графика, звук и редактируемые ресурсы; `scripts/` содержит игровую логику. Сохранения и достижения создаются отдельно в папке данных пользователя.

Готовая версия для Windows доступна на [сайте игры](https://tipochek-klyuch-2026.lightdecor3.chatgpt.site/). Лицензия шрифта Rubik находится в `assets/ui/fonts/Rubik-OFL.txt`.
