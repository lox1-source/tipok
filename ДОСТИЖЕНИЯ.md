# Достижения — реализация

Обновление ранних глав: теперь подключены 12 наград, включая мини-игру Blender, личную сцену Грок, разговор и мозговой штурм Артрея. Ужин имеет отдельное событие и выдаёт AMD только для термопасты. Актуальные условия и проверки — в РАННИЕ_ГЛАВЫ.md; описание ниже отражает первоначальное внедрение менеджера.

В главном меню: «Достижения». Есть прокрутка, семь категорий, фильтр «Все / Полученные / Не полученные», дата, счётчик и процент. Скрытые награды до открытия показывают ??? и загадочную подсказку. Иконки пока текстовые, без внешних ресурсов.

## Создано и изменено

- Создан `scripts/achievement_manager.gd`: каталог, Autoload, сигналы, отдельное сохранение и очередь плавных уведомлений.
- Создан `tests/achievements_smoke.gd`: проверка сохранения, дублей, фильтров, завершения очереди, условий полного прохождения и платины. Тест использует отдельный временный файл и восстанавливает состояние менеджера.
- Изменён `project.godot`: зарегистрирован AchievementManager.
- Изменён `scripts/main_menu.gd`: экран и кнопка достижений, начало прохождения.
- Изменён `scripts/prologue.gd`: реальные события и восстановление наград по сохранённому прогрессу.
- Изменён `scripts/pause_menu.gd`: награда за успешное ручное сохранение.

## Уже доступны в текущей игре

1. `first_launch` — новая игра; также восстанавливается по пройденному вступлению старого сохранения.
2. `first_choice` — выбор в диалоге, включая встроенное демо; старый пройденный диалог главы 1 также подтверждает этот факт.
3. `room_explorer` — взаимодействовать с кроватью, постером, пиццей, шкафом, телефоном и компьютером в прологе.
4. `project_backup` — успешная кнопка «Сохранить игру» в паузе. Это ручное сохранение прохождения, а не резервная копия исходников. Автосохранения награду не выдают.
5. `grok_first_chat` — начало главы 1.
6. `jbt_help` — завершение сцены получения скрипта ЖБТ.
7. `grok_date` — фактическое завершение главы 2 после key.txt.
8. `amd_chef` — завершение текущего ужина/BIOS-главы, где обе существующие ветки подают RAM под термопастой. Нового действия по поеданию термопасты не добавлялось.

Пройденные помощь ЖБТ, первый диалог Грок и завершённая глава 2 восстанавливают соответствующие награды при загрузке старого сохранения. Формат самого сохранения прохождения не изменён.

## Что ожидает новых глав

Остальные награды присутствуют в каталоге, но не открываются без соответствующих событий. Сейчас нет полной мини-игры моделирования, войны вкладок, документа на 84 страницы, Артрея, Министерства, суда, восстановления проекта, личных маршрутов и полноценных концовок. Завершение пролога и главы 2 — контрольные точки; они не выдаются за финалы всей истории.

Добавлено 34-е достижение `instrumental_ending` для плохой концовки отношений из расширенного сценария. `all_endings` требует семь основных финалов: grok, jbt, artbay, artbay_bad, neutral, team, instrumental. Два секретных финала учитываются в платине, но не в этой награде. `platinum` требует все остальные 33 награды, исключая себя.

## Подключение будущих сцен

После фактического события:

```gdscript
AchievementManager.unlock_achievement("grok_without_key")
AchievementManager.report_story_event("tab_war_finished")
# Только после завершения финальной сцены:
AchievementManager.report_story_event("ending", {"id": "grok"})
```

События `report_story_event`: project_backup, model_game_finished, grok_personal_scene, tab_war_finished, document_84_opened, jbt_route_respected, artbay_first_chat, artbay_brainstorm, artbay_suspicion, artbay_reveal, ministry_complete, ministry_stamp, printer_judge, digital_detective, no_extra_files, ending.

ID концовок: grok, jbt, artbay, artbay_bad, neutral, team, instrumental, ministry, triple. Неизвестный ID не выдаёт награды. Система симпатии пока не реализована; случайные значения не добавлялись. Будущая сюжетная логика проверяет отношения и сообщает менеджеру только о подтверждённой сцене/финале.

## Сохранение и уведомления

Отдельный JSON `user://grat_achievements_v1.json`: версия, словарь ID → время получения, общий счётчик. Новая игра не очищает достижения. Повторный ID ничего не меняет. Отсутствующий/пустой/повреждённый файл не прерывает запуск. Ошибка записи выдаёт предупреждение, награда остаётся в памяти текущего запуска. Точные числа симпатии нигде не показываются.

Уведомление находится сверху по центру между портретами, не принимает клики и не приостанавливает игру. Награды показываются последовательно: появление, 2,7 секунды показа, исчезновение. Уже открытые награды в очередь повторно не попадают.

## Проверки

Godot 4.7.2: парсинг после исправления типизации прошёл. Прошли achievements_smoke, systems_smoke, prologue_smoke, chapter_two_smoke, vn_smoke и desktop_smoke. Новый тест проверяет загрузку JSON, повреждение файла, запрет дублей, фильтры, экран, неизвестные финалы, все основные финалы, платину и завершение очереди уведомлений.

В среде проверки Godot не может записать user://logs и прочитать хранилище корневых сертификатов Windows. Проверка JSON использует изолированный файл внутри tests; запись в реальную пользовательскую папку и визуальное расположение в оконном запуске здесь не подтверждены. При выходе headless-тесты также сообщают об оставшихся ресурсах. Тестовые награды не сохраняются в пользовательский прогресс.
